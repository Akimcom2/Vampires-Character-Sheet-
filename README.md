# Vampire: Blood Pool in Discipline Roll

Независимый модуль для Foundry VTT и системы **WoD20**, добавляющий расход Запаса крови непосредственно в окно применения вампирской Дисциплины.

## Важно: независимость модулей

`vampire-bloodpool-dialog` и `wraith-pathos-dialog` — два самостоятельных модуля.

Вампирский модуль:

- не требует установки модуля призраков;
- не использует код, настройки или данные модуля призраков;
- не изменяет Пафос;
- не обрабатывает актёров типа `Wraith`;
- может быть включён или отключён независимо.

Модуль призраков, в свою очередь, не является зависимостью вампирского модуля и не управляет Запасом крови.

Оба модуля разрешено использовать одновременно в одном мире Foundry VTT.

| Модуль | ID | Тип актёра | Ресурс |
|---|---|---|---|
| Vampire: Blood Pool in Discipline Roll | `vampire-bloodpool-dialog` | `Vampire` | Запас крови |
| Wraith: Pathos in Arcanos Roll | `wraith-pathos-dialog` | `Wraith` | Пафос |

## Возможности

### Расход Запаса крови

В окно броска Дисциплины добавляются:

- переключатель **«Использовать Запас крови»**;
- поле **«Стоимость»**;
- отображение доступного количества крови.

При нажатии **«Бросок»** модуль:

1. Проверяет состояние переключателя.
2. Получает введённую стоимость.
3. Проверяет текущий Запас крови персонажа.
4. Списывает указанное количество крови.
5. Запускает исходный бросок WoD20.

Если крови недостаточно, бросок отменяется и появляется уведомление с требуемым и доступным количеством.

При выключенном переключателе бросок выполняется штатно, без расходования крови.

### Только броски Дисциплин

Панель Запаса крови добавляется только к полному окну способности, содержащему разделы **«Описание»** и **«Система»**.

Она не появляется при обычных бросках:

- характеристик;
- способностей;
- инициативы;
- поглощения;
- других стандартных проверок персонажа.

### Переименование характеристики

Модуль визуально заменяет:

| Исходное название | Новое название |
|---|---|
| Привлекательность | Внешность |

Замена применяется:

- на странице характеристик вампира;
- после переключения вкладок листа;
- в заголовке окна броска;
- в формуле пула костей.

Внутренний ключ характеристики и сохранённое значение не изменяются. Это позволяет сохранить совместимость с формулами WoD20 и существующими персонажами.

## Установка

1. Остановите Foundry VTT.
2. Распакуйте каталог `vampire-bloodpool-dialog` в:

   ```text
   FoundryVTT/Data/modules/
   ```

3. Запустите Foundry VTT.
4. Откройте нужный мир.
5. Перейдите в **Управление модулями**.
6. Включите **Vampire: Blood Pool in Discipline Roll**.
7. Выполните `Ctrl+F5` у мастера и игроков.

Итоговый путь к манифесту:

```text
FoundryVTT/Data/modules/vampire-bloodpool-dialog/module.json
```

Модуль `wraith-pathos-dialog` устанавливать для работы вампирского модуля не нужно.

## Обновление

1. Остановите Foundry VTT.
2. Удалите старый каталог `vampire-bloodpool-dialog`.
3. Распакуйте новую версию в `Data/modules`.
4. Запустите Foundry VTT.
5. Выполните `Ctrl+F5`.

Данные персонажей при обновлении не изменяются.

## Использование

1. Откройте лист вампира.
2. Откройте бросок нужной Дисциплины.
3. Включите **«Использовать Запас крови»**.
4. Укажите стоимость — например, `1`, `2` или `3`.
5. Нажмите **«Бросок»**.

После успешного списания отображается уведомление:

```text
Запас крови: −2 (5 осталось)
```

## Определение персонажа

Модуль работает только с актёрами типа `Vampire` и пытается определить персонажа в следующем порядке:

1. Актёр, переданный окном броска.
2. Владелец предмета или Дисциплины.
3. Выделенный токен на активной сцене.
4. Персонаж, назначенный текущему пользователю.

Если мастер вызывает Дисциплину из окна, которое не передаёт актёра напрямую, следует предварительно выделить токен нужного вампира.

## Хранение Запаса крови

Основной путь текущего ресурса:

```text
system.advantages.bloodpool.temporary
```

Резервный путь совместимости:

```text
system.advantages.bloodpool.value
```

Модуль изменяет только текущее значение Запаса крови. Максимум и предел расхода за ход не изменяются.


- `README.md` — документация модуля.

## Технические особенности

- Модуль использует собственный ID `vampire-bloodpool-dialog`.
- Обрабатываются только актёры типа `Vampire`.
- Переключатель реализован независимо от штатных чекбоксов WoD20.
- Поле стоимости изолировано от автоматической перерисовки формы.
- Ширина панели синхронизируется с секцией сложности.
- Русский лист определяется по заголовку `ВАМПИРЫ: МАСКАРАДА`.
- Поддерживаются хуки приложений Foundry VTT поколений V1 и V2.
- Файлы `wraith-pathos-dialog` не импортируются и не вызываются.

## Проверка после установки

1. Откройте страницу характеристик вампира.
2. Убедитесь, что отображается **«Внешность»**.
3. Нажмите на Внешность и убедитесь, что окно броска также использует новое название.
4. Убедитесь, что в обычном броске нет панели крови.
5. Откройте бросок Дисциплины.
6. Укажите стоимость `2` и включите расход крови.
7. Выполните бросок и проверьте, что списано ровно 2 пункта.
8. Укажите стоимость выше доступного запаса и убедитесь, что бросок отменён.

## Известные ограничения

- После крупных обновлений WoD20 могут потребоваться новые селекторы окон.
- Автоматическая установка по URL манифеста пока не настроена.
- Модуль не контролирует игровой предел расходования крови за ход: мастер и игрок учитывают его по правилам персонажа.

## Сообщение об ошибке

При создании issue приложите:

- версию Foundry VTT;
- версию WoD20;
- версию модуля;
- тип актёра;
- скриншот окна;
- сообщения консоли браузера (`F12` → `Console`);
- ожидаемое и фактическое поведение.
